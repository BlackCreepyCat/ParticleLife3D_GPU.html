WebGPU is not available

On Chrome and Edge, WebGPU needs version 113 or newer and a GPU that is not blocklisted. On Linux the Vulkan flag sometimes has to be enabled. The canvas 2D build of the same program runs everywhere.

Particle Life

WebGPU engine: forces, spatial grid and integration all run in compute shaders. The particles never travel back to the CPU.

Setups

The JSON file holds the settings and the matrix in plain text, editable by hand. It is interchangeable with the canvas 2D build.

View: wheel zooms, middle click or Shift + drag pans, double-click reframes.
Keys: Space pauses, R respawns, M draws a new matrix, 0 reframes, H hides the panel.
A setup file can also be dropped straight onto the view.

Range drives the cost: the grid holds about 0 particles per cell, and each one examines nine of them. Past 60 per cell, lower the range rather than the population.
